# ShellBench v1.0

ShellBench v1.0: the benchmark behind Paper 1. A GB-code RC frame family, a thin-shell floor library, whole-building A1-A3 embodied carbon, and the frozen verdicts on hypotheses H1-H4.

**Contents**
- Anchor (v0.1): the thesis building reproduced under gravity, wind and earthquake, with every difference above 10 % explained (`docs/anchor_report.md`).
- Generator and family (v0.2-v0.4): 36 conventional buildings sized by design rules R1-R16 (`docs/design_rules.md`), and 5,184 shell-floor rows (36 floor variants × 4 toppings per building). Dataset DOI: 10.5281/zenodo.24194144 (v0.4.0, CC BY 4.0).
- Shell floor: force-density form-finding, CalculiX shell analysis (MacNeal-Harder checks), tie and buckling sizing, and the rigid-diaphragm test (`docs/floor_concept.md`).
- Verdicts (v0.5): H1 partly supported, H2 and H3 not supported, H4 partly supported (`docs/preregistration.md` section 3; `results/verdicts_*.csv`, `results/surrogate_*.csv`).
- Checks: global equilibrium asserted on every frame analysis and on every static shell run with nodal forces; thrust and load-balance tests on the committed shell results.
- `scripts/reproduce.py`: one command for every result in `results/` that Paper 1 uses (`--quick` for a self-test).

Screening-level, elastic, code-level analysis under the stated assumptions. No claim of seismic safety.

Tests: pytest, 275 passed (with CalculiX). Python 3.12. Licence: MIT (code); CC BY 4.0 (dataset).
