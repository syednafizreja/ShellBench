# Building family dataset (dataset DOI version)

ShellBench v0.4.0: the 36-building family of GB 50010 / GB 50011 RC frames with two floor systems, conventional beam and slab and thin-shell vaults, with quantities and A1-A3 embodied carbon. This is the version the Paper 1 verdicts and the ShellForm hand-over use.

**Data** (`results/`, described column by column in `docs/data_card.md`)
- `family_rc_r14_building_v2.parquet` / `.csv`: conventional floor, one row per building (36 rows; 33 ok, 2 outside the code, 1 failed).
- `family_shell.parquet` / `.csv`: shell floor, one row per building x floor variant x topping (5,184 rows; 4,856 ok, 288 outside the code, 40 failed).
- `family_shell_diaphragm.csv`: the diaphragm test behind `diaphragm_rigid`.
- `day31_checks.csv`: same building IDs in both files, failure counts, carbon sums and three hand-recomputed pairs (all pass).
- Each family file has a `.provenance.json` (package versions, git commit, analysis seed).
- Every row carries `release = "v0.4.0"`. Rows marked "pre-release, not for results" in earlier versions are superseded.

**Gate passed (Day 33, 11 Nov 2026)**: `python scripts/reproduce.py` rebuilt every result from the code; the only differences were the known ones (line endings, and the last printed digit of a few CalculiX utilisations; no pass flag changed). The Day 31 checks pass.

**Not in this release**: the H1-H4 verdicts (Day 32 and Day 47, run once on this data), footings, and the roof as a shell (the roof stays a slab).

Screening-level, elastic, code-level analysis under the stated assumptions. No claim of seismic safety.

Tests: pytest, 238 passed. The release data were built in a Linux cloud run (Python 3.13, OpenSeesPy 3.8.0.0, CalculiX 2.21); the laptop environment is `environment.yml` (Python 3.12, CalculiX 2.23). Each `.provenance.json` names the versions used. Code licence: MIT. Data licence: CC BY 4.0 (`docs/data_card.md`, part 2).
